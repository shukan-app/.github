# Shukan

## 概要・目的

Shukan (就管・習慣) は、就職活動における煩雑な管理を本人が気にすることなく、本質的な作業にフォーカスできるようにするために作られています。
最終的な目標として、「就職活動をする際は、このサービスを利用しておけばOK」という状態を目指しています。

## 既存の課題

現在、就職活動を行う際は、「マイナビ」や「サポーターズ」などの様々な就職活動サービスを利用することが当たり前になっています。
そして、その「複数サービスの利用」は、以下の問題を引き起こします。

- 複数の就活サービスで、同じ会社からメッセージや招待が届く。
- 自分が会社と、どのサービス経由でやり取りしているのか、どこからメッセージや招待をもらっているのかがわからない。
- 申し込んだイベントがどの就活サービスのイベントなのかがわからない。
- 大量にメールが届くので、迅速に対応するべきメールとそうでないものを自分で仕分ける必要がある。

また、別の課題として、会社によって設けている連絡手段が異なるということも挙げられます。
なので、就活をしている人は連絡手段についても管理する必要があります。

- メールに返信をした後に、送信専用だったと気づく。
- マイページからのみ返信可能。
- 基本的にマイページを利用しているが、返信はメールで行う必要がある。
